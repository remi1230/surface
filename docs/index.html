The equation parser expands shorthand notation automatically

You write Expands to
cu→cos(u)
sv→sin(v)
cufv→cos(u*v)
2u→2*u
m→m() — multiplicative cosine
o→o() — additive cosine
R→h(x,y,z) — distance from origin
q(a,b,t)→mix(a,b,t) — interpolation
